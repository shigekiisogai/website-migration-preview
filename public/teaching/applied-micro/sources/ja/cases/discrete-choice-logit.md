# 離散選択モデルによる需要予測と推定

## 問い

**問い：価格を上げると、販売数と利潤はどう変わるでしょうか。**

## 概要

::: {.level-content data-level="1"}
ドリンクA・Bと「買わない」の3択です。Aの価格を上げると、Aが選ばれる割合は下がります。一方で、1本売れたときの利幅は大きくなります。この2つの動きを、スライダーで見比べてみましょう。
:::

::: {.level-content data-level="2"}
各選択肢の効用を価格と品質で表し、ロジット（logit）モデルで選択確率を計算します。同じ属性に同じ係数を持つ1,000人が1回ずつ選ぶ仮想市場では、選択確率は予測市場シェアになります。
:::

::: {.level-content data-level="3"}
個人の選択から係数を推定し、その係数を用いて価格変更時の需要を予測する流れを体験します。個票データの最尤推定と、集計シェアからの需要推定は、データの単位と識別の条件を分けて学びます。
:::

## 実例：商品選択を分析する

交通手段や商品の選択は、離散選択（discrete choice）モデルの応用例です。McFadden（1974）は条件付きロジットの基礎、Berry（1994）は差別化された商品の市場シェアから需要を分析する方法を学ぶ入口として取り上げます。**実例・文献説明はAI作成・原典未確認**です。

## 適用範囲と限界

ここでは、実在の商品・企業・消費者の数値を使わず、ドリンクを選ぶ架空の市場を作ります。推定係数や売上予測を実際の事業判断に使うには、対象市場のデータと仮定の検証が必要です。

## モデル

::: {.level-content data-level="1"}
このモデルでは、価格が低く、品質が高い商品ほど選ばれやすくなります。「買わない」もあるので、両方の商品が高くなると購入そのものを見送る人が増えます。

1,000人のうちAを選ぶ確率が30%なら、Aの予測販売数は300本です。利潤（profit）は「価格と単位当たり費用の差 × 販売数」で計算します。品質を変えたときの費用増加は、この実験では省略しています。
:::

::: {.level-content data-level="2"}
価格 p は円、品質 q は0〜5の教材指標です。商品 j の観測可能な効用を次のように置きます。

$$V_j = -1.2\frac{p_j}{100}+0.9q_j,\qquad V_0=0.$$

0は「買わない」を表します。個人ごとの効用 Uᵢⱼ = Vⱼ + εᵢⱼ の誤差が、標準的な第I種極値分布に独立・同一に従うと仮定すると、

$$P_j=\frac{\exp(V_j)}{1+\exp(V_A)+\exp(V_B)},\qquad P_0=\frac{1}{1+\exp(V_A)+\exp(V_B)}.$$

市場規模 M = 1,000、単位当たり費用 c = 80円、固定費用0円として、

$$Q_j=MP_j,\qquad \pi_j=(p_j-c)MP_j.$$

この係数は仮定した値です。価格の係数−1.2は100円当たりの効用の変化を表します。自己価格弾力性は −1.2(pⱼ/100)(1−Pⱼ) となり、価格とシェアにも依存します。
:::

::: {.level-content data-level="3"}
効用の水準と誤差の尺度を正規化し、商品間の効用差から係数を識別します。共通係数の条件付きロジットでは、同じ選択集合の全選択肢に共通の項は相殺されます。このデモの「買わない」の属性ベクトルは (0, 0) です。

標準ロジットのIIA（independence of irrelevant alternatives）は、2つの選択肢の選択確率の比が、他の選択肢の属性に依存しないという制約です。似た商品への代替や好みの個人差を捉えるには、nested logitやmixed logitなどの拡張を検討します。

実際の価格は未観測品質や需要ショックと相関し得ます。価格変化の因果効果を論じる際は、価格の内生性（endogeneity）と操作変数（instrumental variables）などの識別戦略を検討します。ここでは価格・品質を外生的に生成した架空データを使います。
:::

## データと推定

スライダーの価格・品質、市場規模、費用はすべて教材用の仮定です。購入しない人を含めた1,000人をシェアの分母にします。丸め前の3つの確率の合計は1です。スライダーを動かすと、同じ係数のもとで予測を再計算します。

::: {.level-content data-level="3"}
推定実験では、1,800人が各1回、A・B・購入しないの3択から選びます。A・Bの価格（100円単位）を1〜5、品質を0〜5の一様乱数で独立に生成し、真の係数 (−1.2, 0.9) のロジット確率から選択を抽出します。生成方法とseedはコードに固定しています。

選択された選択肢を示す yᵢⱼ を使い、対数尤度を最大化します。

$$\ell(\beta)=\sum_i\sum_j y_{ij}\log P_{ij}(\beta).$$

JavaScriptでスコアと情報行列を計算し、ステップ幅を調整するNewton法で更新します。平均スコアの最大絶対値が10⁻⁸未満になったかを表示します。この教材の設計での数値検証を行い、一般の入力データへの推定ツール化は今後検討します。

Berry（1994）につながる単純ロジットの関係は log(sⱼ) − log(s₀) = δⱼ です。市場規模から外部選択肢（outside option）のシェア s₀ を定めること、価格の内生性を扱うことが重要になります。このページで実行する推定は個人の選択データに対する最尤推定です。
:::
